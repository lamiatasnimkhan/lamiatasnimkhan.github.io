### System Architecture

AgroSmart AI addresses agricultural vulnerability by providing precision soil intelligence and crop yield optimization to smallholder farmers:
- **CNN-Based Soil Image Classifier:** Trained a deep convolutional neural network to classify soil types (alluvial, clay, sandy, loamy) from mobile camera images, achieving over 92% classification accuracy.
- **Crop Recommendation Engine:** Blended soil image predictions with environmental features (moisture, temperature, pH, rainfall) to output ranked crop recommendations.
- **Full-Stack Application:** Built an asynchronous Flask backend delivering inference within 120ms, linked to a responsive React.js frontend interface with multi-lingual guidance.
